# Customer Churn Prediction

End-to-end ML project — telecom customers ka churn predict karta hai.

## Live Demo
https://churn-prediction-4xk62xcakaz4lzgbb75seb.streamlit.app

## Tech Stack
- Python, Pandas, Scikit-learn
- Random Forest, SMOTE
- Streamlit, GitHub

## Results
- AUC Score: 0.82
- Recall: 60% (SMOTE se improve kiya)
- Live dashboard pe 1894 churners predict kiye

## How to Run
1. Repository clone 
2. pip install -r requirements.txt
3. streamlit run app.py
